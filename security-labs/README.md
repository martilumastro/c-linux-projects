# Security Labs

This directory contains small security-related experiments and educational implementations developed as part of my personal learning process.

The projects are intended for educational, research, and demonstration purposes. They explore security concepts, common attack techniques, and their underlying mechanisms in order to better understand potential risks and defensive strategies.

All experiments are intended to be conducted in controlled environments and on systems for which appropriate authorization has been obtained.

These projects are learning exercises rather than production-ready tools. Their scope, implementation, and documentation may vary as I continue to develop my skills.

## Scope

- Explore cybersecurity concepts through practical experiments.
- Understand how certain attack techniques work at a technical level.
- Improve my ability to identify risks and reason about defensive measures.
- Maintain a personal record of my progress in cybersecurity.
